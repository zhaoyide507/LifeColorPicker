# 采色生活 🎨

> 把日常照片，酿成一幅画。

「采色生活」是一个帮助大家记录生活的网页应用：上传一组生活照片，AI 会沿着 **拼图 → 色彩种子 → 色板 → 线条种子 → 重构图** 的旅程，把你的日常酿成一幅独一无二的艺术作品。

![流程示例](例图.png)

## ✨ 功能旅程

| 步骤 | 名称 | 说明 |
| ---- | ---- | ---- |
| 壹 | **采集 · 生活拼图** | 上传 16 / 25 / 36 / 81 / 162 张照片，自动中心裁剪为 1:1，用 Canvas 织成 4×4、5×5、9×4、9×9、18×9 五种规格的拼图，支持导出 |
| 贰 | **像素化 · 色彩种子** | 将拼图马赛克化（可调像素密度），生成"色彩种子"，支持导出 |
| 叁 | **提取 · 生活色板** | 调用 **DeepSeek**（多模态）从色彩种子中提取 7×3 色板（3 组 × 7 个十六进制色值），用 Canvas 绘制色板图，支持导出；DeepSeek 不可用时自动降级为本地算法 |
| 肆 | **再生 · 线条种子** | 调用图生图模型 **SeedEdit 3.0** 把色板图转化为流动的抽象作品"线条种子"（送模型的无缝色板，避免白缝被当成网格保留）；生成后自动做**色板色彩校准**——逐像素映射到最近的 21 个色板色并保留明度层次，保证线条种子严格取色于色板，支持导出 |
| 伍 | **重构 · 记忆成画** | 每次点击，**DeepSeek 都会依据色板的情绪即兴构思一个生活场景**，拼装出本次的生图指令（指令会展示在页面上，每次不同），再调用 SeedEdit 3.0 将线条种子重构成具象作品；支持 **油画 / 印象派 / 水墨风 / 漫画风** 四种画风；出图比例与第壹步拼图一致；完成后自动将拼图以 **5% 透明度**叠加其上，叠加前后均可导出 |
| 终 | **采色 · 生活组图** | 一键把已生成的作品竖排合成一张白底组图（拼图 → 色彩种子 → 色板 → 线条种子 → 重构图），支持导出 |

**结果持久化**：已生成的作品（含校准后的线条种子）会自动存入浏览器 localStorage，刷新页面后直接从任意已完成步骤继续，无需重新生成；照片原图不入库，重新生成拼图时需重新上传。

所有模型调用可**浏览器直连**服务商接口；使用本地服务时则经由本机代理转发，手机等受限环境也能正常使用。

## 🚀 运行

**推荐**（双击 `启动服务.bat`，Node 与 Python 二选一，或在本目录执行）：

```bash
node server.js 7778        # Node 版（推荐，零依赖）
python server.py 7778      # Python 版，功能相同
```

- 本机访问：<http://localhost:7778>
- **手机访问**：手机连同一 Wi-Fi，打开 `http://<电脑IP>:7778`（电脑 IP 用 `ipconfig` 查看）

本地服务同时提供**同源代理通道**（`/proxy/deepseek`、`/proxy/volcano`）：页面会优先走该通道转发请求，手机等非安全上下文环境的跨域/预检限制随之消失；代理不可用时自动回退浏览器直连，双保险。

其他方式：

```bash
python -m http.server 7778   # 仅静态托管（走浏览器直连，手机端可能受限）
npx serve .                  # 同上
```

直接双击 `index.html` 打开也可以（Chrome / Edge 直连服务商接口）。

## 🔑 API Key

点击右上角 **「API Key 设置」**，填入：

1. **DeepSeek API Key**（`sk-...`）— 用于第叁步色板提取
   - 获取：<https://platform.deepseek.com/api_keys>
2. **火山引擎 AccessKeyID + SecretAccessKey** — 用于第肆 / 伍步图生图（SeedEdit 3.0，需在火山引擎开通"视觉智能"服务）
   - 获取：<https://console.volcengine.com/iam/keymanage/>

**不配置任何 Key 也能使用**：上传 → 拼图 → 色彩种子 → 本地算法色板 → 组图导出（仅含前三步）照常可用；配置后解锁 AI 色板与第肆 / 伍步（届时第肆 / 伍步面板才会显示）。

Key 只保存在你自己浏览器的 localStorage 中，请求发往 DeepSeek / 火山引擎（经你本机启动的 server 转发），不经过任何其他中间服务器。**请勿把真实 Key 写入代码或提交到仓库。**

## 🧩 技术实现

- 纯原生 HTML / CSS / JavaScript，无构建、无依赖，全部计算在浏览器完成
- 拼图、像素化、色板绘制、比例控制与 5% 叠加均为 Canvas 2D 操作（`js/pipeline.js`）
- DeepSeek：`POST https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`（多模态 + JSON 输出）
- SeedEdit 3.0：`https://visual.volcengineapi.com`（`CVSync2AsyncSubmitTask` 提交任务 → `CVSync2AsyncGetResult` 轮询），请求使用火山引擎 V4 签名（WebCrypto HMAC-SHA256 在浏览器内完成）
- 重构图比例控制：将线条种子补白到拼图宽高比后再送模型，返回图按同一比例中心裁剪，保证与拼图严格一致
