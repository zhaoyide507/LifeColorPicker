使用说明

「采色生活」沿着五步旅程，把一组日常照片酿成一幅画。

  1. 上传照片 —— 选好规格（16 / 25 / 36 / 81 / 162 张），点击、拖拽或 Ctrl+V 粘贴上传；
  2. 生成拼图 —— 照片自动裁为 1:1，织成网格拼图，可导出；
  3. 像素化 —— 把拼图压成马赛克"色彩种子"，可调整每张照片的像素密度；
  4. 提取色板 —— 配置了 DeepSeek Key 时由 AI 提取 7×3 色板；未配置时自动使用本地算法；
  5. 线条种子 & 重构（需配置火山引擎 AK/SK）—— 色板晕染成流动的抽象画，再按你选的画风重构成具象作品，并自动叠加 5% 拼图；
  6. 导出组图 —— 任一作品生成后，即可竖排合成一张组图导出。

🔑 关于 Key：不配置任何 Key 也能完成「上传 → 拼图 → 色彩种子 → 本地色板 → 组图导出」；配置后解锁 AI 色板与第肆 / 伍步。Key 仅保存在本浏览器，不会上传到任何第三方。

📱 手机访问：电脑上运行 node server.js（或 python server.py），手机连同一 Wi-Fi 打开 http://电脑IP:7778；请求经本机代理转发，无需担心跨域限制。

💾 已生成的作品会自动保存在本地，刷新页面不丢失；照片原图不保留，重新生成拼图时需重新上传。
